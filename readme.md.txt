# Task 1 - Scan Your Local Network for Open Ports

## Objective

To discover active hosts and open ports in the local network using Nmap.

## Tools Used

* Kali Linux
* Nmap

## Commands Used

nmap --version

ip a

ip route

sudo nmap -sS 10.0.2.0/24

## Network Range

10.0.2.0/24

## Outcome

Learned network reconnaissance, host discovery, TCP SYN scanning, and basic port analysis.
